# Todo Management

As a user, I want to manage my todo items.

## Business Rules

BR-001: A user can create a new todo by entering a non-empty title and pressing Enter.

BR-002: Newly created todos appear in the active list.

BR-003: A user can mark an existing todo as completed.

BR-004: Completed todos appear in the Completed filter.

BR-005: A user can remove a todo from the list.
